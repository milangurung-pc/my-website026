Git Basics & Workflow Guide

A comprehensive hands-on introduction to essential Git commands and GitHub collaboration workflows.

Git is a distributed version control system that helps developers track changes, collaborate effectively, and manage codebases of any scale. This guide covers the foundational steps to get your project version-controlled and hosted on GitHub.

Core Workflow Steps Covered:

  1. 1. Initializing the Repository

    Start tracking your project locally by converting a directory into a Git repository.

    git init

  2. 2. Staging and Committing Changes

    Prepare your modified files for a snapshot and save them to your local repository history with a meaningful message.

    
              git add .
              git commit -m "Initial commit: Add HTML structure and content"

  3. 3. Connecting Remote GitHub & Pushing

    Link your local repository to a remote repository hosted on GitHub and upload your local commits.

    
              git remote add origin https://github.com/username/repository-name.git
              git branch -M main
              git push -u origin main

  4. 4. Branching & Pull Requests (PRs)

    Isolate new features or bug fixes on separate branches without affecting the main code, then submit a Pull Request on GitHub for peer review and merging. 

    
              git checkout -b feature/new-layout
              # (make changes)
              git add .
              git commit -m "Add new page layout"
              git push origin feature/new-layout
